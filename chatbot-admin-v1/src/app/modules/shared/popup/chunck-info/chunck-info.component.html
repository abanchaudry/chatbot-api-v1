Chunks Strategy

Understanding different chunking approaches

General

Splits content into equal-sized text chunks

Simple and fast to implement

Best for basic file processing or when context isn't crucial

Semantic

Splits content based on meaning and structure

Preserves logical paragraph or section boundaries

Ideal for documents like FAQs, articles, or research papers

Agentic

Advanced chunking for AI agent workflows

Optimized for interaction, recall, and agent memory use

Best for dynamic assistants and contextual learning
